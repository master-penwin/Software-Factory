Ask: what did this step teach the factory?

- The user corrected something: generalize it into a rule.
- Something failed or surprised: write the rule that would have prevented it.

Put the rule in the factory repo (default ~/Desktop/Software-Factory), in README.md or the skill it belongs to. Use the fewest words that work. Commit and push.

If nothing generalizes, skip it.
