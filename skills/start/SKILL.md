---
name: start
description: Start a new product with the software factory.
disable-model-invocation: true
---
Create the product as its own git repo, next to the factory (e.g. ~/Desktop/<Name>).

Write two files, nothing else:
- README.md: one plain line saying what the product is.
- CLAUDE.md: "Built with the software factory. README.md is the spec, plan.md the checklist."

Then run /factory:grill.
