Write plan.md: one line saying what it is, then a checklist.

- Each slice delivers something that runs end to end, and says how it's checked.
- Riskiest slice first.
- Usual tail: diverge on look, polish, publish.
- Outside accounts (phone numbers, API keys, paid tiers, terms to accept)? Slice 0 gets each one working by hand; trial limits hide there. Walk the user through it in full: where to click, what to paste, what they'll see.

The user approves the plan, not the code.
